Для реализации системы аналитики Aerobic.Space тебе понадобятся три группы формул: расчет точности, расчет предвзятости и агрегированные показатели для дашбордов.

### 1. Расчет точности (Отклонение)
Эта формула применяется к каждой индивидуальной оценке судьи.

**Базовая разница:**
$$\Delta = |Score_{referee} - Result_{category}|$$
*Где:*
* $Score_{referee}$ — оценка конкретного судьи из `assessments.csv`.
* $Result_{category}$ — итоговая оценка по категории (`result_type_assessment`).

**Логика присвоения статуса (Светофор):**
Статус определяется через условие (IF-ELSE) на основе порогов из ТЗ:

| Итоговый балл ($Result_{category}$) | Допуск ($Limit$) | Статус "Зеленый" | Статус "Красный" |
| :--- | :--- | :--- | :--- |
| **8.00 – 10.00** | $0.3$ | $\Delta \le 0.3$ | $\Delta > 0.3$ |
| **7.00 – 7.99** | $0.4$ | $\Delta \le 0.4$ | $\Delta > 0.4$ |
| **6.00 – 6.99** | $0.5$ | $\Delta \le 0.5$ | $\Delta > 0.5$ |
| **0.00 – 5.99** | $0.6$ | $\Delta \le 0.6$ | $\Delta > 0.6$ |

*Примечание: Если $\Delta = 0$, это подкатегория "В яблочко".*

---

### 2. Расчет предвзятости (Bias)
Эта формула рассчитывается для каждого судьи персонально на основе всей истории его оценок.

**Шаг 1: Среднее отклонение по "своим":**
Нужно найти все выступления, где регион судьи совпадает с регионом участника.
$$AvgDiff_{own} = \frac{\sum (Score_{referee} - Result_{category})}{N_{own}}$$

**Шаг 2: Среднее отклонение по "чужим":**
Берем все остальные выступления того же судьи.
$$AvgDiff_{others} = \frac{\sum (Score_{referee} - Result_{category})}{N_{others}}$$

**Шаг 3: Итоговый коэффициент предвзятости:**
$$Bias = AvgDiff_{others} - AvgDiff_{own}$$
* **Если Bias > 0:** Судья завышает баллы "своим" (так как отклонение по чужим больше, чем по своим).
* **Если Bias < 0:** Судья занижает своим или слишком строг к ним.
* **Норма:** Значение близкое к 0.

---

### 3. Агрегатные показатели (для Дашбордов)

Для графиков и таблиц соревнований тебе понадобятся проценты попадания:

**Процент попадания в коридор (Accuracy %):**
$$Acc\% = \frac{Count(\Delta \le Limit)}{Count(Total\_Assessments)} \times 100\%$$
*Вычисляется отдельно для бригады исполнения (EXECUTION) и артистизма (ARTISTIC).*

**Среднее отклонение по соревнованию (Deviation Score):**
$$AvgDev = \frac{\sum \Delta}{Count(Assessments)}$$
*Чем ниже этот показатель, тем более профессионально и слаженно сработала судейская бригада.*

### Подсказка по данным:
В файле `assessments.csv` у тебя есть два типа итогов:
1.  `result_type_assessment` — используй его для расчета **точности судьи** (сравнение с его типом: Art или Exec).
2.  `result_assessment` — это сумма всех баллов за выступление (включая сложность), для формул точности конкретного судьи он **не нужен**.
