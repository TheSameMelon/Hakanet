# Проект Tobkvant для хакатона Хаканет 2026
Веб-сайт Aerobic Space+ для аналитики судейсва
## Функционал
1. Список судей, с интерактивными элементами
2. Профиль судьи с аналитикой
    * Средняя точнсть оценивания по категориям
    * Коэфициент предвзятости по категориям
    * Список выступлений, которые судья оценивал с отклонением от итоговой оценкой
    * Тепловая карта предвзятости по регионам
    * **Нововведение**: показатель строгости, он отражает насколько судья завышает слабым работам и занижает сильным.
3. Список соревнований с средней точностью оценок по категориям
4. Профиль соревнования с коэфициентом девиации, списком выступлений и фильтром.
5. Загрузка данных
6. **Нововведение**: Архивация данных. При загрузке данных создаётся папка с данныим, между которыми можно переключаться.
